# 🌿 Glow Nest – Skincare Frontend Website

A simple and modern skincare-themed frontend project built using **HTML, CSS, and Bootstrap 5**.


## ✨ Features
- Neumorphism-style soft UI
- Responsive design with Bootstrap Grid
- Custom product showcase
- Smooth contact form layout
- Hover effects with subtle transitions

## 📁 Tech Stack
- HTML5
- CSS3 (Neumorphism & Glow UI)
- Bootstrap 5

# **⚙️ How It Works**

• HTML is used to create the structure of the website

• CSS is used for styling, layout, and responsiveness

• JSON stores product details such as product names, prices, images, and descriptions dynamically
